# NetWasm NativeTools

Pinned native build recipes and release assets for tools used to build NetWasm applications. The first planned asset is `wasm-ld` for Windows ARM64, built from pinned LLVM source on a native GitHub Actions runner. Built executables belong in versioned GitHub Releases, not Git.

This repository and its `wasm-ld` release assets use LLVM's [Apache-2.0 license with LLVM Exceptions](LICENSE.txt). Each release archive includes the pinned upstream license and a build receipt.
